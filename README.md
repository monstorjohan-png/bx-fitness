## 3) المعاينة محليًا

افتح `index.html` مباشرة في المتصفح. لا يحتاج أي خادم.
لخادم محلي: `python -m http.server 8080` ثم افتح `http://localhost:8080/`.

---

## 4) النشر (استضافة مجانية دائمة)

- **GitHub Pages:** أنشئ مستودعًا باسم `bx-fitness` → ارفع الملفات → `Settings → Pages → Deploy from a branch → main / (root)`.
- **Netlify Drop:** افتح `https://app.netlify.com/drop` واسحب المجلد كاملًا (يلزم حساب مجاني لتفعيل الرابط).
- **Cloudflare Pages:** `Workers & Pages → Create → Pages → Upload assets`.

الدومين الحالي في `sitemap.xml` و`canonical` مؤقت: `https://monstorjohan-png.github.io/bx-fitness/` — يُستبدل عند ربط الدومين النهائي.
